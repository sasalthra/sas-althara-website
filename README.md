# ساس الثراء — الموقع ولوحة الإدارة

نسخة Next.js مخصصة لـHostinger مع MySQL ودخول Google المقصور على حساب الإدارة المعتمد.

## التشغيل والتعديل

افتح المجلد في VS Code. ثبّت Node.js 22.13 أو أحدث ثم نفّذ npm ci، وبعدها npm run dev. العنوان المحلي http://localhost:5173.

للبناء: npm run build. للاختبارات: npm test. للتشغيل الإنتاجي: npm start.

app/page.tsx للرئيسية، app/site-header.tsx للهيدر، app/sas-brand.css للألوان والخطوط، app/crm للإدارة، data/properties.json للعقارات، public للصور.

## النشر

اتبع [دليل Hostinger](HOSTINGER.md). انسخ .env.example إلى .env.local محليًا، وأدخل القيم الحقيقية في متغيرات الاستضافة عند النشر. لا ترفع الأسرار إلى GitHub.

الدخول مغلق حتى إعداد Google، وحفظ العملاء يحتاج قاعدة MySQL مستقلة واستيراد db/mysql/001_leads.sql. لا ترفع المشروع إلى public_html كموقع PHP.

النسخة تحتوي 87 عقارًا، و30 سجلًا معلّقًا في ملفات التدقيق المنفصلة. ما زالت بعض الروابط تشير للموقع القديم وتحتاج المعالجة قبل استبداله. Google وMySQL الفعليان يحتاجان اختبارًا على الرابط المؤقت؛ الاختبارات المحلية لا تؤكد إعدادهما.
